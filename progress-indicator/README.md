# Progress Indicator

Shows half-filled status circles for partially played podcasts and iTunes U items in Apple's individual-item lists. Unplayed and completed items keep their stock indicators; group and All rows keep Apple's behaviour. An unfinished replay shows a half circle even if the item was played before.

The indicator follows the saved resume position, or the live position when that item is playing. Audio and video variants keep the stock outline and colours.

Disabling it restores the stock icons.

| | |
|---|---|
| Default | on |
| Memory | image, plus 16 bytes per list model it has drawn in, freed with the model or on disable |
| Settings | none |
| Minimum SDK | 1.42 |
