# Chapter Marks

The Now Playing bar draws a mark at the start of every chapter. A long audiobook, or a podcast with a chapter every minute, turns that into a solid block that says nothing about where the chapters are. Once the marks would average under 3 px of bar each, about 55 chapters on the classic's bar, this extension leaves them all out and the bar looks as it does for a track without chapters. Fewer chapters keep their marks exactly as stock draws them.

| | |
|---|---|
| Default | on |
| Memory | image only, plus 8 bytes for the bar being drawn |
| Settings | none |
| Minimum SDK | 1.44 |
